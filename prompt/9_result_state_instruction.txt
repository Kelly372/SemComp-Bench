- "preserve_ignore_en" and "preserve_ignore_zh": exactly 1 sentence.

For "video_description":
- Describe only the visible content of the outcome video and do not mention the reference image.
- Use the video goal and original instruction only to identify the main subject and main visual state; do not invent details that are not visible in the video.
- The first sentence should focus on the main subject and its most important visible attributes.
- Describe the main object attributes, main visual state, scene presentation, and clearly visible important actions.
- For the main subject, include relevant details when visible: category, count, color, material, texture, surface appearance, shape, structure, size, height, width, position, spatial relation, orientation, viewing angle, pose, action, expression, arrangement, and completion level.
- If the main subject is a person or animal, describe visible clothing, pose, gesture, facial expression, body orientation, and interaction when relevant.

- Describe secondary objects, people, tools, or background elements only when they help explain the action, scale, scene, or result.

- State which information should remain consistent with the reference image, using the alignment type and preserved attributes as guidance.
